# Конвертер валют

Нативное Android-приложение для конвертации RUB, USD, EUR и VND. Курсы загружаются с `fxapi.app` при открытии приложения и затем каждые пять минут, пока приложение на экране. В фоне запросов нет. Последний успешно загруженный курс сохраняется на устройстве и доступен без сети.

Поправка курса настраивается в диапазоне от −100% до +100%; значение по умолчанию — 0%, без поправки. Экран показывает время обновления из ответа API.

## Что нужно установить

1. Android Studio и предложенный установщиком Android SDK.
2. В SDK Manager: Android SDK Platform 36 и Android SDK Build-Tools 36.x.
3. JDK 17 для запуска Gradle. На macOS `gradlew` автоматически выберет установленный JDK 17, даже если Android Studio поставляется с более новой Java.
4. Для проверки: эмулятор Android 8.0+ (API 26+) либо Android-телефон с включённой отладкой по USB.

Приложение собирается с `compileSdk 36`, `targetSdk 36` и поддерживает устройства начиная с Android 8.0 (API 26).

## Открыть и собрать

Откройте эту папку в Android Studio и дождитесь синхронизации Gradle. При первом запуске Gradle скачает закреплённую версию 8.11.1 и проверит её SHA-256; для этого нужен интернет. Если IDE попросит установить SDK-компоненты, согласитесь. Затем выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. APK для установки будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Источник курсов

API: [fxapi.app](https://fxapi.app/), обновление данных заявлено раз в пять минут. На экране показывается timestamp, возвращённый API. Приложению нужен интернет для обновления курсов.
